# Bigex Cars

A futuristic, mobile-first car marketplace prototype.

## First version

- Cinematic dark/glass visual system
- Responsive landing page
- Featured vehicle card
- Search with quick brand tags
- Vehicle category filters
- Curated vehicle listings
- Save/unsave shortlist interaction
- Bigex Intelligence-style car request UI
- Compare workflow preview
- Seller listing entry point

## Run

No build step is required. Open `index.html` in a browser or deploy the repository with any static hosting service.

## Next build

Connect the UI to real vehicle data, authentication, seller profiles, image uploads, favorites persistence, real comparison, location-aware discovery, messaging, and AI-powered matching.
